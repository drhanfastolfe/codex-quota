# Dependencias y herramientas

| Proyecto | Uso | Versión de referencia | Licencia del proyecto |
| --- | --- | --- | --- |
| Kotlin | Lenguaje, compilador y biblioteca estándar | 2.1.20 | Apache 2.0 |
| Gradle | Construcción y wrapper | 8.13 | Apache 2.0 |
| Android Gradle Plugin | Construcción Android | 8.9.2 | Apache 2.0 |
| JUnit | Pruebas locales | 4.13.2 | EPL 1.0 |
| Robolectric | Entorno Android simulado para pruebas | 4.14.1 | MIT |

| AndroidX Core | Compatibilidad de los receptores entre versiones de Android | 1.15.0 | Apache 2.0 |

Las dependencias de prueba no se incluyen en el APK de distribución. Gradle conserva los avisos y licencias de sus artefactos; las herramientas SDK se distribuyen por separado bajo sus propios términos.

La recuperación inicial del código de 0.1.6 se inspeccionó con [JADX](https://github.com/skylot/jadx) 1.5.6 (Apache 2.0) y [Apktool](https://github.com/iBotPeaches/Apktool) 3.0.3 (Apache 2.0). Ninguna de estas herramientas es necesaria para construir esta versión.

Android, ChatGPT, Codex y OpenAI son nombres de sus respectivos titulares. Su uso identifica la plataforma y los servicios con los que se integra la aplicación; no implica afiliación ni respaldo.
